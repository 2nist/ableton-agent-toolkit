New in this revision

  • 1Dotted step lanes — the detour lane is retired; every lane is a row of editable steps (click = toggle, drag = velocity). Zoom subdivides the grid; off-grid hits render as ◇ until you zoom.
  • 2Marquee = the interface — drag beats × drums; the range becomes the editable selection (isolation dims the rest).
  • 3XY pad, docked right — the pad + mode buttons live in one cluster anchored to the selection's right edge (connector line), so the pattern stays visible while you shape it. X = rotation ↻, Y = hits k; the necklace ring is the live Euclidean reference.
  • 4Multi-drum = interleave — one rhythm distributed across the selected drums by priority (KICK ▸ SNR ▸ TOM ▸ PERC); necklace dots colour per drum, lanes show their share.
  • 5Motion mode — the same pad sets transitions/energy gestures (↗ build · ↖ crescendo · ↓ break · ↙ thin); distance = intensity.
  • 6⤢ Selection editor — enlarged modal with Steps / Euclid / Motion / FX modes and the per-step inspector.
  • 7Step FX — velocity, nudge, gate, probability, ratchet, flam per step; swing, humanize, quantize, vel curve per range. Deterministic bake keeps all four outputs identical.
  • 8Compact tags — tiny mono chips (9/16 ↻3, MOTION ↑70%, 5/8, TACET) replace block boxes, domes, hexes and energy gutters.
  • 9Zoom & dot growth (next pass) — dots scale and the grid subdivides ½ → ×4 so steps stay easy to hit; implemented with the same pointer work as the pad (shared hit-testing, drag + velocity gestures).

Kept / retired

  • Kept: bar/beat ruler + the amber split grid inside decoupled ranges (5/8 HAT), zoom pill, playhead, draft flow (● preview · Apply/Revert).
  • Kept: the whole engine — transitions, variation/detour data, voice overrides still export exactly as before; old songs unchanged; everything here compiles through planSectionDrumNotes.
  • Retired: DETOUR row + arcs · static necklaces on lanes · fill domes · transition hexagons · block boxes / energy gutters · Pattern/Detour/Transition dock tabs (folded into the editor modes).
  • Later: zoom + dot-growth pass (with the pad's pointer controls) · X-axis alt-modes (pattern change / step duration) · native Ableton probability + velocity deviation · an AI mode chip that sets k/n/rotation from a prompt.
